# Data files

- `original_emails.csv`: 16 seed messages (8 spam, 8 legitimate). In this starter package these are student-created fallback examples, not an instructor-provided file.
- `emails.csv`: generated by `python generate_dataset.py`; contains each seed plus three small variations. The `original_id` column links related versions.
- `features.csv`: generated by `python prepare_data.py` from `emails.csv`.

If your instructor later supplies the intended source template, use those 16 examples in place of the fallback seed data and regenerate the variations.
